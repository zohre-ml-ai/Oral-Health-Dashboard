# Oral Health Management Dashboard

## Project Overview
A management dashboard prototype designed to support monitoring and analysis of oral health services at the county level.

The dashboard was developed using Microsoft Power BI and synthetic data to demonstrate how service performance, human resources, and equipment status can be presented in a unified management view.

## Dashboard Pages
- **Executive Overview:** High-level performance indicators.
- **Service Performance:** Service delivery, visits, target achievement, and screening coverage.
- **Human Resources:** Staffing and service-hour indicators.
- **Equipment Status:** Equipment availability, maintenance needs, and downtime.

## Tools
- Microsoft Power BI
- Data modeling and relationships
- DAX measures
- Interactive filters and visual analytics

## Data Disclaimer
All data used in this prototype are synthetic and intended for demonstration purposes only. The displayed values do not represent actual healthcare facility performance. KPI definitions and calculations may require validation by the relevant stakeholders before operational use.

## Project Status
Initial dashboard prototype completed. The dashboard has been submitted for review and is awaiting feedback on its structure and management indicators.
